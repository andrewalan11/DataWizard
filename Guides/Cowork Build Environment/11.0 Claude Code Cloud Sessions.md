# 11.0 Claude Code Cloud Sessions

Behaviors of Claude Code sessions that run in Anthropic's cloud (started from claude.ai/code, the desktop app's Code tab with Cloud, `claude --cloud` or the mobile app), as distinct from a Cowork session with a linked computer. Several of these rest on a product setting or promotion that can change: read the live source before you plan around one.

- **A promotional credit for cloud sessions did not cover Cowork tasks.** The promotion's support article lists claude.ai/code, the desktop Code tab with Cloud, `claude --cloud` and mobile as covered. A plan that put Cowork scheduled tasks on the credit was wrong; work meant for the credit has to start from one of the listed surfaces. This is a snapshot of one promotion (Conventions Registry, "Carry the probe, not the snapshot"): read the live article before you rely on it. (DataWizard, 2026-10)
- **A cloud session reaches a private repository only when the Claude GitHub App is installed on it.** An app that is listed under "Authorized GitHub Apps" for the account is not enough. Install it at github.com/apps/claude, then Configure, then choose selected repositories, and pick only the repository the session needs rather than "all repositories" when other repositories on the same account should stay out of reach. (DataWizard, 2026-10)
- **A cloud session cannot create a repository.** `gh repo create` from the session answered with a proxy 403. The operator creates the repository and installs the app on it; the sessions then push their work to their own branches. (DataWizard, 2026-10)
- **The environment's "Limited" network takes one domain per line, and the safety scanners need four hosts beyond the defaults.** `objects.githubusercontent.com` and `release-assets.githubusercontent.com` (release downloads redirect there), `api.osv.dev` and `osv-vulnerabilities.storage.googleapis.com` (OSV-Scanner's advisory data). OSV-Scanner errored until `api.osv.dev` was allowed. A test run on one repository found this before a 28-repository batch. (DataWizard, 2026-10)
- **GuardDog installed only through pipx there.** Use `pipx install guarddog==<pinned version>`; see [[10.0 Scanning Third-Party Code]] for the scanner's own behaviors. (DataWizard, 2026-10)
- **A cloud session can clone a public repository that is not attached to it.** A test clone of an unattached public repository passed. (DataWizard, 2026-10)
