# 39.0 Shared add-only registers

**Rule:** a shared register is a data file that sessions of several projects may add lines to. One project owns it. Any other project's session may add a line, and only in the way below. (DataWizard, 2026-11)

- **Which files count.** Only files listed in the `shared_registers` row of the Paths table in the operator's `Vault Config.md` (vault-relative paths, separated by `; `). Any other file of another project follows the canon write gate and the normal ownership rules.
- **Adding a line.** Add one line at the end of the file. Ask the operator first and add it only on their yes. Put your session id on the line.
- **No edits.** Nobody edits or deletes another session's line. A fix is a new line. The latest line for the same key wins.
- **The owner tidies.** The owning project keeps the line form and does the tidying. It may consolidate only by rotating old lines to an archive file (Archiving, 10.0). It never discards a line.
- **Data, not canon.** A register is data. The canon write gate (15.0) is unchanged: it still covers instructions, VERSION files, protocol docs and 0.x files.
- **Same model as `harvest_log`.** Add-only, latest line wins, each session writes only its own lines (YAML Schema, Harvest Tracking: [[2.0 YAML Schema - Harvest and Federation]]).

## Register types

### Spelling list

A list of names that transcription hears wrong: people, groups, places, tools. The operator names the file in the `spelling_list` row of Vault Config's Paths table and lists the same path in the `shared_registers` row.

**Line form:**

```
- heard | correct | project | core_id | session | note
```

- `heard` - the form the transcript shows.
- `correct` - the right spelling.
- `project` - the project tag of the harvest that heard it.
- `core_id` - optional; the core record's id when one exists, `-` when none.
- `session` - the session id that added the line.
- `note` - optional, and private. It never goes into a shared copy.
- Fields are split on ` | `. Only `note`, the last field, may contain a pipe; put `-` in an empty optional field.

The key is `heard`. A later line with the same `heard` replaces the earlier one.

**What does not go on it.** Everyday words that were misheard. Fix those turn by turn in the harvest, not here.

**Who reads it.** A harvest reads the list before it names people or groups (transcript-harvest, harvest-router Hub mode). If `spelling_list` is not set, skip the step.

**Example:** `- Akme Comons | Acme Commons | AL | acme-commons | AL-S12 | heard twice on one call`
